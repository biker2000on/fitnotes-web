## Specificity verdict
Generic dark SaaS dashboard, not a gym logger: Plus Jakarta Sans, frosted-glass sidebar, gradient wordmark, "Premium Unlocked", "FitNotes Dashboard / Interactive tracking session for <date>" on every page, indigo leftovers under a sky-blue primary. Only Calendar and the set rows feel authored. Detector: 10 CLI warnings (7 side-tab, 2 gradient-text, 1 overused font); overlay: primary #0284c7 fails AA with white text (4.1:1) on every primary button; today's date on Calendar 1.5:1; category colours as text down to 1.5:1 (Abs); buttons fall back to Arial because .btn never inherits the font (index.css:564). 1,135 inline style blocks.
